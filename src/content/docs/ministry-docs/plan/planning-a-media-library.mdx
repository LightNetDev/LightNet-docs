This guide will help a ministry team establish a shared direction before building a
LightNet Media Library.

## Planned topics

- Identify the audiences and ministry goals the Media Library should serve
- Decide which media to publish first
- Define responsibilities for content, review, and administration
- Estimate initial and ongoing costs
- Record decisions that the Site Administrator will need for implementation

Use this page as a planning checklist while the detailed guidance is being developed.
