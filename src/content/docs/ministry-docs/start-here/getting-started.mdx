Welcome to the LightNet Ministry Documentation.

This section is for ministry teams and project owners who are planning, building,
and maintaining a LightNet Media Library. It explains the decisions and recurring
tasks around a project without requiring you to work directly in the source code.

Use the guides in this section alongside the [LightNet Developer Documentation](/start-here/getting-started),
which explains how to configure and extend a Media Library.

## Documentation roadmap

The first version of this section will cover the following areas:

- **Plan**: Define the project's goals, estimate costs, and decide what your team needs
- **Build**: Prepare the accounts and services needed to create and publish a Media Library
- **Concepts**: Learn the main pages, content structures, and language choices in LightNet
- **Administration**: Manage media and other content through the Administration UI

These guides are being developed. Until a guide is available, the section heading in
the sidebar describes the planned topic.

## Suggested starting point

Begin with [Planning a Media Library](/ministry-docs/plan/planning-a-media-library)
to clarify the project's purpose and scope. When you are ready to set up the project,
continue with [Accounts and access](/ministry-docs/build/accounts-and-access).

## Who this section is for

This documentation is intended for:

- ministry leaders and project owners
- content and communications teams
- people responsible for day-to-day administration
- developers supporting the technical implementation

The technical details are linked from the Developer Documentation when a task needs
access to the project repository or deployment configuration.
