---
title: User experience
description: Understand the main pages and navigation in a LightNet Site
---

Users access **Content** provided by a Ministry through a LightNet Site in a web browser.
The User experience is organized around three main pages and a small number of static
pages.

## Main pages

The three main pages are the Homepage, Search Page, and Media Item Details Page.

```text
        Homepage
            |
      Search Page
            |
Media Item Details Page
```

### Homepage

The Homepage is the starting point for a LightNet Site. It introduces the site and helps
Users discover the **Media Items** in it. From the Homepage, a User can go to the Search Page,
select a highlighted Media Item, or open the Main Menu.

### Search Page

The Search Page helps Users find Media Items in the site's **Media Library**. Users can
search for media and use filters to narrow the results.

### Media Item Details Page

Each Media Item has a Media Item Details Page. It provides information about the Content,
such as its title, description, and language, and provides access to the
Content.

## Header Bar

The Header Bar appears at the top of the LightNet Site. It identifies the site and
contains, from left to right, an optional logo, the site title, access to the Search Page,
the Language Selection Menu, and the Main Menu.

### Language Selection Menu

The Language Selection Menu allows Users to choose the **Site Language**. Changing the
Site Language changes the language of the site's user interface, but does not change the
**Content Language**.

### Main Menu

The Main Menu is not one of the three main pages. It is a navigation menu that provides
access to Static Pages.

## Static Pages

Static Pages contain information about the Ministry or the LightNet Site rather than
describing a Media Item. They are typically accessed through the Main Menu.

Most sites have an About page, although some sites may not need one. In general, a
LightNet Site should have only a small number of Static Pages.

## Examples of LightNet Sites

The following sites show different ways Ministries can organize and share
their Content with LightNet:

- [MediaWorks Digital Library](https://library.mediaworks.global/) provides media
  resources in many languages for least-reached people groups.
- [Nadija – Hope](https://nadija.org/) provides Christian resources in Ukrainian.
- [Food for Thought](https://food-for-thought.mediaworks.global/) is a collection of
  articles relating the Bible to a wide variety of topics.
