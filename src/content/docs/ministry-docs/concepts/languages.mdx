---
title: Languages
description: Understand site languages and content languages in LightNet
---

LightNet lets you build websites in your community's language and supports multiple
languages, including right-to-left languages.

## Site Language

A **Site Language** is the language of the site's user interface, including button labels,
menus, and other user interface elements.

A LightNet Site may have one or more Site Languages. Users can switch from one Site
Language to another in the user interface.

### Add a Site Language

LightNet includes translations for many languages. If a Ministry wants to add a Site
Language that is not already supported, a Site Administrator can add it. For technical
details, see [Internationalization fundamentals](/build/i18n/fundamentals).

## Content Language

A **Content Language** is the language in which a Media Item's **Content** is presented.
For example, it is the language of the written text in a document or the spoken language
of a video.

The Content Language can be different from the Site Language. A LightNet Site could use
English as its Site Language while offering a Media Item with Arabic as its Content
Language.
