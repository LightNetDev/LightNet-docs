---
title: Glossary
description: Definitions of domain-specific terms used in LightNet ministry documentation
---

This glossary defines LightNet terms used throughout the Ministry Documentation and
Developer Documentation. It is intended to give Ministries, Content Administrators, and
Site Administrators a shared vocabulary.

## Administration User Interface

An **Administration User Interface (Administration UI)** is a graphical interface for
managing **[Content](#content)** on a **[LightNet Site](#lightnet-site)**.

## Author

An **Author** is a person or organization that created the **[Content](#content)** of a
**[Media Item](#media-item)**.

## Category

A **Category** is a grouping of related Media Items. Categories help people filter and
organize content in a Media Library.

## Collection

A **Collection** is a group of Media Items arranged as a specific sequence or set, such
as the parts of a sermon series or different editions of a book.

## Content

**Content** is the material made available through a **[LightNet Site](#lightnet-site)**,
such as a video, audio recording, document, image, or book.

## Content Administrator

A **Content Administrator** is an editor who manages the **[Content](#content)** of a
**[LightNet Site](#lightnet-site)** using an
**[Administration User Interface](#administration-user-interface)**.

## Content Language

A **Content Language** is the language in which a **[Media Item](#media-item)**'s
**[Content](#content)** is presented. For example, it is the language of the written
text in a book or the spoken language of a video.

## Contributor

A **Contributor** is a person who helps improve the open-source LightNet project through
feature proposals, bug reports, pull requests, or translation improvements.

## LightNet Site

A **LightNet Site** is an instance of LightNet operated by a Ministry to organize and
distribute Content.

## Media Distribution

**Media Distribution** is the process of delivering **[Content](#content)** to
**[Users](#user)** through a **[LightNet Site](#lightnet-site)**.

## Media Item

A **Media Item** is a single piece of **[Content](#content)** distributed by a
**[LightNet Site](#lightnet-site)**.
It can represent **Content** such as a video, article, book, audio recording, image, or
document. A Media Item includes metadata that describes the **Content** and provides
access to it.

## Media Library

A **Media Library** is the collection of Content organized and made available by a
**[LightNet Site](#lightnet-site)**.

## Media Type

A **Media Type** describes the kind of content represented by a Media Item, such as a
video, audio recording, document, image, or book. Ministries can define additional
Media Types for content that is specific to their work.

## Ministry

A **Ministry** is a Christian organization that serves a local community.

## Site Administrator

A **Site Administrator** is responsible for designing, building, deploying, and
operating one or more **[LightNet Sites](#lightnet-site)**.
The [Developer Documentation](/start-here/getting-started) provides technical guidance
for Site Administrators.

## Site Language

A **Site Language** is the language of the user interface, including button labels,
menus, and page text.

## User

A **User** is anyone who consumes **Content** via a **[LightNet Site](#lightnet-site)**.
