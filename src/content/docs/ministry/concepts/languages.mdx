---
title: Languages
description: Understand site languages and content languages in LightNet
---

LightNet supports multiple languages, including right-to-left languages. A LightNet Site
can use one or more Site Languages for its user interface, while Content is presented in
its own Content Language.

## Site Language

A **Site Language** is the language of the site's user interface, including button labels,
menus, and other user interface elements.

A Site Administrator configures the Site Languages that a LightNet Site supports. Only
those Site Languages are available for Users to select in the user interface. Users can
switch from one Site Language to another through the
[Language Selection Menu](/ministry/concepts/site-navigation/#language-selection-menu).
A Ministry can ask its Site Administrator to add another Site Language.

## Content Language

A **Content Language** is the language in which a Media Item's **Content** is presented.
For example, it is the language of the written text in a document or the spoken language
of a video.

The Content Language can be different from the Site Language. A LightNet Site could use
English as its Site Language while offering a Media Item with Arabic as its Content
Language.
