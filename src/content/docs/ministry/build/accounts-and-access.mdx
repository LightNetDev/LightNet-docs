This guide will describe how to prepare the external services used by a LightNet
project and how to invite the people who need access.

## Planned topics

- Create or confirm the Cloudflare account
- Invite collaborators with the minimum permissions they need
- Create or confirm the GitHub account and organization
- Invite the development team with appropriate repository permissions
- Keep ownership and recovery information available to the ministry

The exact setup steps will be added after the recommended account structure is finalized.
