This guide will provide a step-by-step workflow for adding a new media item through
the Administration UI.

## Planned topics

- Gather the title, description, language, category, and media files
- Create the item and complete its metadata
- Check the item in the Media Library
- Ask another team member to review the content
- Save and publish the Media Item

Until this guide is expanded, use the [Administration UI](/content/administration-ui)
reference for the available workflow.
