The Administration UI is the graphical editor for managing the Content of a LightNet
Media Library. This guide will explain the main areas of the interface and the tasks
that ministry teams can perform there.

## Planned topics

- Opening the Administration UI
- Understanding media items, media types, categories, and collections
- Reviewing changes before publishing
- Working safely with collaborators

For the current technical details, see [Administration UI](/content/administration-ui)
in the Developer Documentation.
